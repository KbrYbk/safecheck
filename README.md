# 🛡 SafeCheck

**SafeCheck** — мобильное приложение для хранения гарантийных чеков и контроля сроков гарантии.  
Приложение помогает не забыть о важных покупках и заранее предупреждает пользователя об окончании гарантии.

---

## ✨ Основные возможности

### 📄 Хранение чеков

- Добавление чеков вручную или через сканирование QR-кода
- Сохранение:
    - названия товара
    - магазина
    - даты покупки
    - срока гарантии
- Локальное хранилище (данные остаются на устройстве)

---

### 📷 Сканирование QR-кодов

- Быстрое добавление чека
- Автоматическое извлечение данных (дата покупки и др.)
- Минимум ручного ввода

---

### 🔔 Умные уведомления

#### ⏰ Локальные уведомления (гарантия)

Персональные напоминания о завершении гарантии:

- за **30 дней**
- за **14 дней**
- за **7 дней**
- в **день окончания**

Особенности:

- Работают **без интернета**
- Срабатывают **точно по времени**
- Не зависят от сервера

---

#### ☁ Push-уведомления (FCM)

Используются для:

- новостей приложения
- обновлений
- важных объявлений

Особенности:

- Работают при закрытом приложении
- Работают после перезагрузки телефона
- Реализованы через **Firebase Cloud Messaging**

---

### 🔐 Авторизация и доступ

- Вход как **гость**
- Регистрация и вход по **email + пароль**
- Авторизация через **Google**
- Гибкая система доступа без принудительной регистрации

## 🧠 Архитектура уведомлений

SafeCheck использует **два независимых механизма уведомлений**:

| Тип уведомлений | Технология                  | Назначение              |
|-----------------|-----------------------------|-------------------------|
| Push            | Firebase Cloud Messaging    | Новости, обновления     |
| Local           | flutter_local_notifications | Гарантийные напоминания |

Такой подход обеспечивает:

- надёжность
- офлайн-доступ
- масштабируемость
